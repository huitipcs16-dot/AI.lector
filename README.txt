AILector — edición Anime Premium

Estructura:
  index.html          página principal
  css/style.css       estilos (incluye la nueva capa visual Premium)
  js/main.js          lógica de la página y funciones
  js/data.js          capítulos y diálogos para la narración
  img/                portadas, logo original, recursos y fondo anime premium
  sw.js               modo offline / caché PWA
  manifest.webmanifest instalación como aplicación

Cambios de esta versión:
  - Se conserva el logo original y todos los archivos de imágenes.
  - Nuevo encabezado de bienvenida Premium en la biblioteca.
  - Ambientación anime con fondo ilustrado, luna, castillo y cerezos.
  - Paleta premium oscura con acentos violeta, azul y rosa mágico.
  - Tarjetas, navegación, comunidad, noticias, formularios y lector con acabado anime premium.
  - Diseño adaptable a escritorio, tablet y móvil.
  - Los botones del encabezado nuevo llevan a la búsqueda y a Comunidad.
  - Se mantienen las funciones y la lógica JavaScript existentes.

Para probar:
  1. Descomprime el ZIP.
  2. Abre sitio-web/index.html en el navegador.
  3. Para las funciones PWA/offline, publica la carpeta en un hosting HTTPS.

Nota: el acceso de usuarios de esta versión original guarda las cuentas en el navegador
(localStorage); no es un sistema de autenticación seguro con servidor.
